# TIMO 數學小挑戰

這個頁面把 Google Drive 上的兩份 TIMO 幼稚園組模擬試整理成一題一題的幼兒練習：

- 2021-2022：掃描檔可讀到 26 題；原檔沒有第 21-24 題頁面。
- 2022-2023：完整 30 題。
- 題目文字以繁體中文幼兒友善版本呈現，保留英文原題及 Drive 來源連結。
- 原題只有文字／算式的題目保留文字顯示；14 題含圖題已按 Drive 原題 PDF 重畫成 SVG，並逐題核對答案。
- 2022-2023 第 24 題按原圖的交點分段計算，共 6 條線段，已完成核對。
- 可按年份、範圍或題目編號直接選題，並用上一題／下一題瀏覽；中文／英文按鈕會切換題目文字。
- 練習進度只放在瀏覽器 localStorage，不會上傳個人資料。

直接從 index.html 進入即可。若要在本機測試，請從 repo 根目錄啟動靜態伺服器：

~~~text
python3 -m http.server 8000
~~~

再開啟 http://localhost:8000/math-challenge/。
